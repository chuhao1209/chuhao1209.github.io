思路和算法:

用 n 表示二维数组 items 的长度。根据题意，所有物品的因数都不超过 n。用 minPrice 表示二维数组 items 中的所有物品的最小价格，遍历二维数组 items 即可计算 minPrice。

为了计算在可以获得免费物品时能够获得的物品最大总数，需要预计算每个物品的因数的倍数在所有物品中的出现次数。计算方法如下。

创建长度为 n+1 的数组 factorCounts，其中 factorCounts[i] 表示所有物品中的因数 i 的出现次数。遍历二维数组 items，对于每个商品 item，其因数是 item[0]，将 factorCounts[item[0]] 的值增加 1。遍历结束之后即可得到数组 factorCounts。

创建长度为 n+1 的数组 multipleCounts，其中 multipleCounts[i] 表示所有物品中的因数值是 i 的倍数的出现次数。遍历 1≤i≤n 的每个整数 i，对于每个整数 i 遍历 i≤j≤n 且 jmodi=0 的每个整数 j，将 multipleCounts[i] 的值增加 factorCounts[j]。遍历结束之后即可得到数组 multipleCounts。

为了使能够获得的物品总数最大化，应遵循如下贪心策略。

只够买价格小于 minPrice×2 的物品，不购买价格大于等于 minPrice×2 的物品。如果购买价格大于等于 minPrice×2 的物品，则换成购买两个价格是 minPrice 的物品，无论是否免费，总花费一定不变或减少，不可能增加。

应按照价格升序的顺序购买每个物品。如果不按照价格升序的顺序购买物品，则在购买一个物品之后可能购买到价格更便宜且能将之前购买的物品免费的物品，导致实际花费大于最低花费，按照价格升序的顺序购买物品可以避免在免费物品上产生额外花费。

对于任意物品，将其因数和价格分别记为 factor 和 price，则因数值是 factor 的倍数的出现次数是 multipleCounts[factor]，排除该物品，其余物品中可以免费获得的物品个数是 multipleCounts[factor]−1。

具体计算方法如下。

使用列表存储物品的价格和免费获得的物品个数的二元组。遍历二维数组 items，对于每个物品 [factor,item]，如果 price<minPrice×2 且 multipleCounts[factor]>1，
则购买当前物品之后可以免费获得的物品个数是 multipleCounts[factor]−1，将二元组 (price,multipleCounts[factor]−1) 加入列表。

将列表按照价格升序排序。

遍历排序后的列表，对于每个二元组 (price,count)，当 price≤budget 时，可以购买当前物品，执行如下操作。

计算在可以免费获得其他物品的情况下，当前物品可以购买的最大数量 currItems，则 currItems=min(count,⌊pricebudget⌋)。

将 budget 的值减少购买当前物品的花费 price×currItems。由于每购买一个当前物品都能免费获得一个其他物品，因此将能够获得的物品的最大总数增加 currItems×2。

遍历结束之后，剩余可使用的花费是 budget 且不能再免费获得物品。为了使能够获得的物品总数最大化，根据贪心策略，
剩余可使用的花费应都用于购买最便宜的物品，如果购买的物品不是最便宜的物品则物品总数不可能更大，此时剩余可使用的花费可以购买的最大物品总数是 ⌊minPricebudget⌋，
因此将能够获得的物品最大总数增加 ⌊minPricebudget⌋。

操作结束之后，即可得到能够获得的物品最大总数。

我的代码：

```cpp
class Solution {
    public int maximumSaleItems(int[][] items, int budget) {
        int n = items.length, minPrice = Integer.MAX_VALUE;
        int[] factorCounts = new int[n + 1];
        for (int[] item : items) {
            factorCounts[item[0]]++;
            minPrice = Math.min(minPrice, item[1]);
        }
        int[] multipleCounts = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            if (factorCounts[i] != 0) {
                for (int j = i; j <= n; j += i) {
                    multipleCounts[i] += factorCounts[j];
                }
            }
        }
        List<int[]> pricesCounts = new ArrayList<int[]>();
        for (int[] item : items) {
            int factor = item[0], price = item[1];
            if (price < minPrice * 2 && multipleCounts[factor] > 1) {
                pricesCounts.add(new int[]{price, multipleCounts[factor] - 1});
            }
        }
        pricesCounts.sort((a, b) -> a[0] - b[0]);
        int maxItems = 0;
        for (int[] priceCount : pricesCounts) {
            int price = priceCount[0], count = priceCount[1];
            if (price <= budget) {
                int currItems = Math.min(count, budget / price);
                budget -= price * currItems;
                maxItems += currItems * 2;
            }
        }
        maxItems += budget / minPrice;
        return maxItems;
    }
}
```
